# ACKS II — Importer

Imports ACKS II book content into Foundry **from your own PDFs**: monsters,
proficiencies and class powers, equipment and price tables, adventure locations
and roll tables.

This module ships extraction *recipes* — page geometry, patterns and anchors —
and never the book text itself. Nothing is read unless you connect a PDF you
own, and the bytes never leave your browser.
